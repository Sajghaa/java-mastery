# Beginner Exercises – Operators

1. Calculate and print the area of a rectangle (width=7.5, height=3.8) using `*`.
2. Check if a given number `num = 15` is divisible by 3 and 5 (use `%` and `&&`).
3. Write a program that increments a variable `x = 10` using `++` in two different ways (postfix and prefix) and prints the results.
4. Swap two integers `p=5`, `q=9` **without** using a third variable (use `+` and `-`).
5. Evaluate: `System.out.println(100 % 7);` and explain the output.
