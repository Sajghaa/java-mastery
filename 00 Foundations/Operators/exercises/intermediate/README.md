# Intermediate Exercises – Operators

1. Write an expression that uses `+`, `-`, `*`, `/` and parentheses to produce `42` from the numbers `10, 2, 5, 3`.
2. Demonstrate type promotion by multiplying a `short` and a `char`, assigning the result to an `int`.
3. Use the ternary operator to assign a message: if `score >= 75` -> "Pass", else "Fail".
4. Compound assignment: declare `byte b = 127;` then `b += 10;` – print `b`. Explain why the value is what it is.
5. Given `String s = "Hello"` and `int n = 5`, what does `s + n + n` print? What about `s + (n + n)`? Write code to verify.
