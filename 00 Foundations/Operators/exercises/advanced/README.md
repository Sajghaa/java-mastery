# Advanced Exercises – Operators

1. Write a method that takes an `int` and returns `true` if it is a power of two. **Do not use loops or `Math`** – use only bitwise operators.
2. Use `instanceof` to safely check if an object is a `String` before calling `.length()`.
3. Demonstrate the difference between `&` and `&&` by writing two expressions where the non-short-circuit version throws an exception but the short-circuit one doesn't.
4. Write a program that uses `>>` and `>>>` on a negative number and prints the binary representation (`Integer.toBinaryString`).
5. Given two bitmasks `READ = 0b001`, `WRITE = 0b010`, `EXEC = 0b100`, combine `READ` and `WRITE` and then check if `EXEC` is present.
