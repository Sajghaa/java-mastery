# Loops in Java – Mastery Module

## 🎯 Objective
Loops are the **repetition engines** of your code.This module covers the **traditional loops** that give you full control over iteration, performance, and complex flow.

## 📖 Theory in a Nutshell

### 1. Traditional `for` (The Control Freak)
Use this when you need an **index** or know exactly how many times to iterate.
```java
for (initialization; condition; increment) {
    // body
}
